# Command Spelling Assistant

**Command Spelling Assistant** is a free, browser-based accessibility tool that spells commands and technical text one character at a time.

It was created to help learners who may have difficulty visually tracking exact strings of text, especially when working with commands, code, file paths, URLs, or other technical instructions where every character matters.

## Live Tool

Use the tool here:

https://kanders2002.github.io/command-spelling-assistant/

## What It Does

Paste a command or technical string into the tool and select **Spell Command**.

The assistant will read each character individually and name common symbols such as:

- space
- slash
- backslash
- hyphen
- underscore
- dot
- pipe
- plus
- asterisk
- quotation marks
- parentheses
- brackets
- and more

The current character is also displayed visually while it is being spoken.

## Features

- Character-by-character spelling
- Spoken names for common symbols
- Visual display of the current character
- Pause and resume controls
- Repeat current character
- Previous and next character controls
- Restart command
- Adjustable speech speed
- Optional character-position announcements
- No account required
- No installation required

## How to Use

1. Copy the command or technical text you need to enter.
2. Open the Command Spelling Assistant.
3. Paste the text into the input box.
4. Select **Spell Command**.
5. Listen and follow along as each character is spoken.
6. Use the playback controls whenever you need more time.

## Who It May Help

This tool may be useful for learners who benefit from auditory support when working with precise technical text, including students with dyslexia, visual tracking difficulties, or other accessibility needs.

It can also be useful for anyone who wants an easier way to verify commands character by character.

## Privacy

The text entered into the Command Spelling Assistant is processed locally in the user's browser.

The website does not intentionally upload, store, or transmit the text entered into the tool.

## Accessibility

This project is intended as a supplemental accessibility aid and not as a replacement for formally approved accommodations or assistive technology.

Students should continue to work with their institution's disability or accessibility services when accommodations are needed.

## Browser Support

The tool uses the browser's built-in speech synthesis functionality and should work in most modern browsers, including:

- Google Chrome
- Microsoft Edge
- Safari

Speech voices and behavior may vary slightly depending on the browser and operating system.

## Technology

The project is intentionally lightweight and uses only:

- HTML
- CSS
- JavaScript
- Web Speech API

There are no external libraries, accounts, or backend services required.
